# Traifast Website

A lightweight static website for Traifast Enterprises Company Limited.

## Files
- `index.html` — website content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and year
- `assets/` — place the final Traifast logo/images here

## Cloudflare Pages
Recommended deployment: Cloudflare Pages.

For a simple static site, there is no build step. Use:
- Production branch: `main`
- Build command: `exit 0` (for Git integration)
- Build output directory: `/` (the repository root, where `index.html` lives)

Then attach `traifast.com` as a custom domain in the Cloudflare Pages project.

## Before launch
1. Replace the text T logo with the official Traifast logo.
2. Confirm the company phone number and any social links.
3. Confirm product categories and company wording.
4. Add privacy/terms pages if the site will collect visitor information.
